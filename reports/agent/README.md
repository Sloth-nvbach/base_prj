## Report Format
Each Jira task report follows the standard template:
1. Thông tin chung (General Info)
2. Mục tiêu và Acceptance Criteria
3. Khảo sát ban đầu (Initial Survey)
4. Nhật ký thực hiện (Execution Log)
5. File thay đổi (Files Changed)
6. Kiểm thử và xác minh (Testing & Verification)
7. Acceptance Criteria Status
8. Jira Operations
9. GitHub Operations
10. Blockers & Remaining Work
11. Next Steps
12. Session History
