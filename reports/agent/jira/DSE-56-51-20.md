## 2. DSE-51: Rubric Data Model & CRUD ✅ COMPLETE

### Model (`BE/src/models/rubric.model.ts`)
- **Rubric**: assignmentId (unique), criteria[] (name, description, weight, maxScore, order)
- **Criterion**: Embedded subdocument with validation
- **Weight Auto-Normalization**: Pre-save hook normalizes weights to sum=100 proportionally
- **Validation**: Duplicate criterion names rejected, min 1 criterion with weight>0, weight 0-100, maxScore 1-100

### CRUD APIs (`BE/src/routes/rubric.route.ts`, `BE/src/controllers/rubric.controller.ts`, `BE/src/services/rubric.service.ts`)
- GET/POST/PATCH/DELETE `/api/rubrics/assignment/:assignmentId` (upsert on create)
- GET `/api/rubrics/default` - returns default rubric template
- Role-based access: teachers own assignments, admins all, students published only

### Validators (`BE/src/validators/rubric.validator.ts`)
- Criterion schema with all constraints
- Rubric create/update schemas

### Tests: **ALL 17 TESTS PASSING** (`BE/tests/integration/rubrics.test.ts`, `BE/tests/integration/rubric-model.test.ts`)
